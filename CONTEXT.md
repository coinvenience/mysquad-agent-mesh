# Workspace Context Contract
## Purpose
Autonomous tool repository and shared knowledge graph for MySquad agent mesh (HermesLocal, HermesVPS, Cursor, Claude).

## Pipeline Stages
- `01_telemetry/`: Live health monitoring, latency probes, node status.
- `02_pipeline/`: Automated task distribution and cross-agent event routing.
- `_shared/`: Reusable Python tool modules and MCP client wrappers.
- `_references/`: ICM contracts, soul definitions, and agent identity rules.
